# Family Chore & Pet Enrichment System

**Household:** Lucas · Jonah · Peter · Daniel · Shannon

**Pets:** Puppy (10-week-old) · Axolotl

---

## How the Rotation Works

Five family members are distributed evenly across Monday–Friday using a cyclic Latin square. Each person handles exactly one responsibility per day, and no one is assigned the same slot twice in the same week.
